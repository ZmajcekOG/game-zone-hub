# Game Zone Hub

A lightweight Python project featuring an interactive number guessing game and a random player card generator.

## Features
- **Player Card Generator:** Creates random player statistics with ratings.
- **Number Guessing Game:** Interactive CLI mini-game with dynamic feedback.

## How to Run
1. Make sure Python 3.x is installed on your system.
2. Run the script using the command:
   ```bash
   python main.py
